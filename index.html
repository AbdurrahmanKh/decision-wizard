What the files look like
Round. Either a bare array of questions, or an object {config, questions} where config sets {title, tagline, product}. Each question: id, section, title, options (array of strings). Ids must be unique, and so must row ids inside one batch. Optional: question (the question itself, shown large, with the title as a small topic line above it; the sidebar keeps the title); context; detail (array of {kind: quote, note, or code, src, text}; code keeps indentation and line breaks and shows src exactly as written, such as a file path and line); links (array of {label, url}); extra ({label, blocks:[{kind: text, text}, {kind: table, title, columns, rows}, {kind: quote, src, text}, {kind: note, text}, or {kind: code, src, text}]}, or a list of them for several buttons) for context popups; customLabel; custom: false; skip: false; recommend (the label of the recommended option) with because (the reason, finishing "I recommend this because"), on a question, a follow-up, or a batch row. For a batch table set type: "batch" and items: [{id, label, note}], sharing one options set per row. Every question and every row takes a note with the pen. type: "rank" makes a ranking of 2 to 10 options (recommend is the whole order); "number" takes min, max, step, and unit instead of options (recommend is a number); "bracket" runs 4 to 32 options in knockout pairs, in the listed order. In config, needs_wizard names the oldest wizard version the round is made for.
Saved file. What Save writes: the answers JSON (meta and answers, the same as Copy answers JSON) with the whole round under round, so opening it picks up where you left off.
Answers JSON. Answers on their own merge into the round with the same title, or into the open round: matching ids overwrite, and open entries are ignored unless they carry a note. A note comes back as comment.
Backup. What Back up all rounds writes: every round in this browser with its answers, each in the saved-file form, under rounds. Loading a backup adds the rounds that are missing here and brings back the ones the backup has a newer copy of. When a round changed here after the backup was made, the wizard asks whether to keep it.
The list. Every round stays in this browser, with its answers, until you delete it. A round whose title is already in the list replaces the saved one, and answers to questions that did not change stay.
